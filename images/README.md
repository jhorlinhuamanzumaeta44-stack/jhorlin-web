# Fotos JHOKA SNACK

## Solo sube tus fotos
No necesitas editar `index.html`, `script.js` ni `style.css`.

Usa estos nombres base:

- `banner` → foto principal de portada
- `chifle-clasico` → producto clásico
- `chifle-especial` → producto especial
- `chifle-picante` → producto picante

Formatos aceptados: **PNG, JPG, JPEG y WEBP**.

Ejemplos:
- `banner.png`
- `chifle-clasico.png`
- `chifle-especial.jpg`
- `chifle-picante.webp`

### Importante
Para que una foto aparezca automáticamente, conserva el nombre base indicado arriba. La extensión puede ser PNG, JPG, JPEG o WEBP.

Después de subir una foto, espera unos segundos y actualiza la página.
